Sincronização com o projeto Orçamento H&P, isolada em receitas_onca_books, receitas_onca_devices e receitas_onca_recipes. Buckets privados receitas-onca-images. Os papéis anon/authenticated não têm acesso direto. A Edge Function receitas-onca-sync autentica pelo código de convite do livro e emite token aleatório por aparelho, guardado criptografado no Android Keystore. A chave service_role fica somente no ambiente Supabase da função. Não gravar códigos de livros reais no repositório.

Entrar com o mesmo código em todos os celulares. Todos os portadores do código podem ler, editar e excluir receitas do livro. Sincroniza ao abrir, após alterações e a cada 30 segundos com o app em primeiro plano. Offline mantém receitas e fila local. Fotos são reduzidas/comprimidas JPEG para economizar armazenamento. Vídeos ficam fora da sincronização nesta versão. Edições simultâneas preservam uma cópia local que é enviada como nova receita. Exclusões são tombstones para propagação aos outros aparelhos. Dados locais existentes são enviados após conectar o livro; o Bolo de fubá usa identificador fixo para evitar duplicação.

Teste de integração no GitHub Actions com livro temporário isolado: duas sessões, upload/download de fotos, versões, edição e exclusão, código errado, token desconhecido e isolamento entre livros. Ainda necessário teste em aparelhos Android com modo offline e reconexão; não substituir esse teste pela compilação.
